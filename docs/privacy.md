# Privacy Policy — ALT COIN PREDICTION 3.0

## What this GPT does
This GPT calls Coinbase public market-data endpoints (products, candles, ticker, order book) to analyze prices and send spike alerts. It does not require user login or API secrets.

## Data we access
- Public market data from Coinbase.
- Your prompts and the GPT’s outputs are processed by OpenAI as part of normal ChatGPT use.

## What we do NOT collect
- No personal identifiers, API keys, account balances, or trading permissions.
- No selling or sharing of personal data.

## If private access is added later (optional)
If a separate proxy is added for balances or trading, API keys remain only on that proxy. This GPT never stores or receives your secrets. This policy will be updated to include the proxy host, logging, and retention.

## Retention
No additional storage outside ChatGPT. Coinbase data is fetched on demand.

## Security
Only public Coinbase endpoints are used. Any future proxy will use least-privilege keys and IP allowlisting.
