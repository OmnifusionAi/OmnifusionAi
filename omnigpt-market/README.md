# OmniGPT Market

This is a lightweight HTML5 site that displays and monetizes a growing library of ChatGPT models (currently over 60+), organized by function and available via weekly subscriptions.

## 🔹 Features

- Categorized GPT listing (from models.json)
- Weeklong free trial badge on eligible models
- $1.99/week per GPT, or 10-for-$10 bundle pricing
- Search/filter by function (Productivity, Image, Assistant, etc.)
- Direct links to each model's ChatGPT URL
- Scalable structure for adding new GPTs anytime

### Testing

This project doesn't include automated tests yet. Running `npm test` simply outputs a placeholder message.
